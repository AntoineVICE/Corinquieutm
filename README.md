# 修道院游戏工程

已接入作者提供的宿舍、外院、菜园与鸡舍、厨房、药舍和南回廊对白，使用真正的 Ink 分支与存档。第一次进入南回廊会强制播放安布罗斯与塞维里诺的交谈；结束后塞维里诺离场，安布罗斯留下，可询问莱比锡进修一事。返回和读档不会重播已完成的开场。

目前共 12 个地点。宿舍及其余全景使用用户原画，主角使用原始左右行走帧。七张新人物图已接入：菲利普在外院，瓦茨拉夫与西蒙在菜园，罗德里戈在厨房，安布罗斯与塞维里诺在南回廊，普热比斯拉夫在章会厅。每个人按可见身体高度匹配主角、以脚底落地；菜园采用相同的固定场景比例。外院背景、未提供的人物美术和正式音乐仍待补充。

已接入用户提供的对话侧边栏、探索边框和手形交互素材。探索时只显示场景与交互；对话时羊皮纸从右侧滑入，文字选项透明，悬停或键盘聚焦时仅变色。场景名称、时间、目标、操作说明和原型标记均已移除。小手保持固定大小，不展开横条；对白使用宋体、独立的人名行和更宽的页边距，滚动条隐藏，滚轮仍可回看。

## 先运行

1. 在 Godot 项目管理器中导入本目录的 `project.godot`。已用本机 Godot 4.7.2 标准版验证，无需 .NET 版。
2. **按 F5 运行正式游戏。** 主场景为 `scenes/main.tscn`，包含南回廊强制开场和所有已接入交谈。工程自带已编译的对白，首次运行无需另外安装插件或编译。
3. 默认以 PC 全屏运行；F11 或 Alt+Enter 切换全屏／窗口。A/D 或左右方向键移动；菜园、章会厅、厨房和病舍还可用 W/S 或上下方向键沿可走地面前后走，人物不随远近缩放；靠近物品后按 E 或直接点击固定的小手按钮打开对白。点击回答文字或按 1–9 选择；点击“继续”或按 E／空格推进；滚轮回看当前交谈。J 打开日志，Esc 打开菜单；二者不在探索界面常驻显示。
4. 要重看起床剧情，在菜单中选择“重新开始第一天”。单独运行地点场景不会有完整主角与界面，请用 F5 运行整个游戏。

## 改对白：只需三步

1. 用文本编辑器或 Inky 修改 `story/` 中对应地点的 `.ink`（下表列出），保存为 UTF-8。
2. 双击根目录的 **编译对白.cmd**。窗口显示 `OK: story/day1.json updated` 表示成功。若报错，按报错的文件与行号修正文案再编译；原来的可运行 JSON 会保留。
3. 停止正在运行的游戏，重新按 F5。日后修改剧本结构时建议从菜单“重新开始第一天”验证。本次扩展已对上一版地图工程的存档做专项兼容，保留位置和燕麦口信等选择；其他未经验证的剧本版本仍会拒绝载入，不覆盖原存档。

`story/day1.ink` 是总入口，包含变量声明和六个章节文件。始终编译总入口，不能分别编译缺少全局变量的章节文件。`story/day1.json` 是编译产物，不要手动编辑。

Inky 可编辑并预览 Ink；为保持与运行库的匹配，游戏使用本工程提供的 inklecate 1.1.1 编译。Inky 打开 `story/day1.ink` 可以预览起床对话；场景切换、物件触发及外院完整流程在 Godot 中体验。

## 换美术和音乐

把素材拖进 Godot 文件系统中的 assets 文件夹，再设置对应节点的检查器属性：

- 打开地点场景，选根节点。Background Texture 接背景；Foreground Texture 接遮挡前景；Music / Ambience 接音乐和环境声。
- 选 Interactions 下的 NPC。Portrait Texture 接人物全身立绘，Portrait Bounds 填实际人物的像素边界（不包括画布留白），Portrait Height 默认 343。脚底自动对齐交互点，菜园会乘上该场景的 0.73 比例；有导出残留的原图可使用 Portrait Outline 在显示时裁切。
- 打开 `scenes/player.tscn`，根节点的 Idle Texture / Idle Texture Left 分别接右／左站立图，当前使用各方向 A0。Walk Frames 已接 `assets/characters/protagonist/walk_frames.tres`，包含 `walk_right`、`walk_left` 两组 A0–A5，按 8 帧／秒循环。
- 主角根节点的 Art Scale 当前为 0.26，可统一调整人物大小；这是原始 1440 × 2560 透明画布的缩放值，实际可见人物约高 343 个设计单位。两个精灵都用左上角定位、位置 (-720, -1991)，固定原画共同的脚底基准。不要按每帧不同的透明边界分别居中，否则走路会晃动。
- 宿舍使用完整原画，等比缩放至 1280 × 720 设计坐标，脚底 y = 654，镜头显示整间房。外院暂为 1600 × 720，脚底 y = 570。地点根节点的 Walk Y / Walk Left / Walk Right 决定行走位置与边界。
- 界面设计坐标仍为 1280 × 720，实际全屏输出随显示器分辨率变化。交互点的 Marker Offset 用来将手形提示对齐画面中的物件，不会把角色移动到墙上的十字架处。

对白和场景解耦。更换图片、音频不会要求重写 Ink。

## PC 全屏与分辨率

默认使用 Godot 的 Exclusive Fullscreen 模式。1280 × 720 是场景与 UI 的设计坐标，不是最终画面的像素上限。Canvas Items 模式按显示器实际分辨率绘制文字、界面与 2D 内容；1080p、1440p、4K 会分别等比适配。

F11 或 Alt+Enter 随时切换显示模式；菜单中也有按钮。切回窗口时恢复本次运行记住的窗口大小。更改显示模式不影响 Ink 剧情状态。

当前保留 16:9 构图。16:10 和超宽屏会留边，不横向拉扯人物，也不会露出背景之外的区域。窗口最小为 960 × 540。如果 Godot 正在显示上一次运行的画面，先按 F8 停止，再 F5；若编辑器提示工程设置在外部变更，请重新加载。

正式位图素材的清晰度仍取决于原图：高分辨率图片可以在设计坐标中缩放使用，低分辨率原图不会因全屏而增加细节。宿舍背景已使用 4K 原画，主角使用原始透明 PNG 帧；七张 NPC 原图保存在 `assets/characters/npcs/`，未改写原始图片。

## 接一个新对白

在章节 `.ink` 中增加一个命名段落，例如 `=== inspect_window ===`，填写文字并用 `-> END` 收尾。编译后，在地点场景中实例化 `scenes/interactable.tscn`，把 Kind 设为 DIALOGUE，Dialogue Id 填 `inspect_window`，移动到窗边即可。完整例子见接入说明。

## 框架与存档

Main 常驻，LocationSlot 一次只装一个地点，Player、HUD、Audio 保留。Godot 调用 Ink 的段落，Ink 决定下一句和可选回答；HUD 只做展示。Ink 变量为剧情事实来源，GameState 把这些事实提供给门、人物显隐和日志。

本版使用独立存档 `user://story_day1_ink_v3.json`，不覆盖此前 v2 或占位演示存档。结束对话与切换地点后自动保存，也能从菜单手动保存。包含位置、朝向与完整 Ink 状态（变量、访问次数和流程信息）。界面目前只提供交谈之间的保存，不提供对白中途保存与恢复历史阅读栏。

## 行走、遮挡与转场

- 所有全景画均保留原始 PNG，按 1/3 等比显示，横向镜头跟随。原画以外的素材没有替换。
- 菜园固定人物比例为基础尺寸的 0.73 倍，比最初菜园增大约 12%。其他地点沿用原来人物比例。前后走动不改变人物大小，也不自动变焦。
- 菜园、章会厅、厨房、病舍的 `Walk Polygon` 定义脚底可走范围，W/S 控制浅纵深，纵向速度为横向的 0.6 倍。章会厅避开立柱、讲台、桌子及台阶，保留左右走道和前方空地。
- `Walk Obstacles` 是实物落地范围。菜园的石块、树桩、渔具、鸡舍、柴堆，以及厨房和病舍靠通道的木桶、杂物、炉台与柴堆不可穿过。按小步检查移动，长帧不会越过障碍；有空地时可用 WASD 绕行。
- 餐厅前排桌子与桌面器物使用原图轮廓作前景遮挡。菜园两只鹅与七只鸡有独立轮廓，`scripts/scenery_occluder.gd` 根据人物脚底与动物落脚高度切换前后顺序。这里只处理静态画面的遮挡，没有增加动物动画。
- 出入口采用 0.28 秒淡出、0.42 秒淡入。装饰边框保持稳定，画面遮住时完成加载、出生点与镜头定位；转场期间锁住移动与重复交互。按需加载当前全景，避免启动时同时载入全部大图。
- 读档时保留横纵坐标和朝向；如果旧落点处新增了障碍，移到附近可走地面，不重置 Ink 剧情。

行走帧保留原始 PNG，统一使用线性采样与无损导入。源图中部分运动帧较软，运行时对 A1–A5 做轻度清晰度补偿，A0 保持原样。
